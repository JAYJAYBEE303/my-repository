{%- comment -%} ============================================================================= wiki-status.html — the right rail's Entry status block. Usage, from _layouts/wiki-entry.html: {% include wiki-status.html revised=wk_revised backs=wk_backs_count %} Every number here is computed at build time, so the block is complete with JavaScript off — unlike the two blocks above it in the rail. Notes counts the ((…)) footnote markers in the source, which is the same convention _includes/wiki-body.html compiles. Splitting on the opening delimiter and subtracting one counts openings, so an unclosed note would be counted; that would already be visibly broken in the prose. The design sheet's "Locally edited" row is deliberately absent. It reports on an in-browser edit mode this site does not have. A count of zero prints nothing. "Notes 0" and "Inbound links 0" are not status, they are the absence of it — the rail was spending two lines to say a section has no footnotes, which is the ordinary case. Revised is not a count and always shows. Every row can therefore vanish except Revised. That is fine: .wk-stats is a plain grid with a gap, so it collapses to whatever rows survive, and the block always keeps its heading and at least the one row. ============================================================================= {%- endcomment -%} {%- assign wk_note_count = page.content | split: "((" | size | minus: 1 -%} {%- assign wk_word_count = page.content | strip_html | number_of_words -%}
